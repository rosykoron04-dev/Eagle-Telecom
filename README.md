# Load Bazar Android Demo

এই ZIP-এ Android Studio-এর জন্য একটি Java ভিত্তিক Load Bazar demo project আছে।

## আছে
- Login / Registration UI
- Home dashboard
- Balance Deposit
- Mobile Banking (bKash/Nagad/Rocket/Upay)
- Bank Transfer
- Mobile Topup (Prepaid/Postpaid)
- Drive Offer (GP/Robi/Banglalink)
- Bill Pay categories
- Group Chat / Special Offer / Customer Care / Review / Tutorial / About placeholders
- Transaction History
- Profile / Password / PIN / Logout UI

## গুরুত্বপূর্ণ
এটি ভিডিও দেখে বানানো **UI/demo source project**। এতে কোনো আসল payment gateway, recharge API, OTP, server/database বা টাকা লেনদেনের backend সংযুক্ত নেই। এগুলো চালু করতে আলাদা backend/API এবং নিরাপদ authentication প্রয়োজন।

## Android Studio
Project folder `LoadBazarApp` Android Studio-তে Open করুন। Gradle sync করে Run করুন।
